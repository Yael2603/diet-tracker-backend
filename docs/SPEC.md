# מסמך אפיון (מאושר): "מסלול בריא"

## א. תיאור הפרויקט
| | |
|---|---|
| **שם** | מסלול בריא |
| **מטרה** | ללוות אדם בתהליך דיאטה: הוא בוחר מסלול ותפריט, עוקב אחרי המשקל שלו, רושם ארוחות ומקבל ציון יומי, ויכול לשתף את הנתונים עם דיאטן ולהתייעץ איתו |
| **קהל יעד** | כל אדם מבוגר (18 ומעלה) |
| **משתמשים** | **משתמש רגיל** (USER) ו**דיאטן/מנהל** (ADMIN) |

**חישובים אוטומטיים בשרת:**
- **ציון יומי (0–100)** לפי יעד הקלוריות של המסלול. בטווח 80%–110% מהיעד הציון הוא 100. על כל אחוז מחוץ לטווח יורדות 2 נקודות.
  סטטוסים אפשריים: NO_TRACK, NO_DATA, UNDER (פחות מ-80%), ON_TARGET (80%–110%), SLIGHTLY_OVER (110%–125%), FAR_OVER (יותר מ-125%).
- **אחוז התקדמות**: (משקל התחלתי − משקל נוכחי) ÷ (משקל התחלתי − משקל יעד), בין 0 ל-100.
- **עמידה בתפריט**: כמה פריטים מהתפריט נאכלו ביום, מתוך כמה פריטים יש בתפריט.

## ב. מסכים (5 למשתמש, 4 לדיאטן)
**משתמש רגיל**
| מסך | מה כולל |
|---|---|
| כניסה | התחברות והרשמה במסך אחד |
| הבית שלי | התקדמות, ציון היום, פרופיל, מתג שיתוף, ושקילות (רשימה, הוספה, עריכה, מחיקה) |
| מסלול ותפריט | בחירת מסלול, ואחריה בחירת תפריט מתוך התפריטים של המסלול |
| יומן אכילה | בחירת תאריך, "התפריט שלי להיום" עם כפתור "אכלתי ✓", רשימת הארוחות, וסינון "מהתפריט / מחוץ לתפריט" |
| פניות | הפניות שלי ושליחת פנייה (רק כשהשיתוף דולק) |

**דיאטן/מנהל**
| מסך | מה כולל |
|---|---|
| משתמשים | רשימה, חיפוש, חסימה/הפעלה. לחיצה על משתמש מציגה את הנתונים שלו, אם הוא משתף |
| מסלולים ותפריטים | ניהול מסלולים, ובתוך כל מסלול ניהול התפריטים שלו |
| מאכלים | ניהול מאגר המאכלים, עם חיפוש וסינון |
| פניות | רשימה, סינון לפי סטטוס, ומענה |

## ד. מסד הנתונים
8 טבלאות: `users`, `tracks`, `menus`, `menu_items`, `foods`, `weight_entries`, `meal_entries`, `consultations`.
הפירוט המלא (שדות, טיפוסים, מפתחות ואילוצים) נמצא ב-`prisma/schema.prisma`. הסבר פשוט נמצא ב-[HOW-IT-WORKS.md](HOW-IT-WORKS.md).

**אילוצים עיקריים:**
- אימייל ייחודי.
- שם מסלול ייחודי, ושם מאכל ייחודי.
- שם תפריט ייחודי בתוך המסלול שלו.
- **שקילה אחת ליום לכל משתמש.**
- אותו מאכל לא מופיע פעמיים באותה ארוחה בתפריט.
- לא ניתן להזין תאריכים עתידיים, וגיל חייב להיות 18 ומעלה.
- מסלולים, תפריטים ומאכלים לא נמחקים, רק מושבתים.

## ה. Endpoints (36)
הרשימה המלאה עם ההרשאות נמצאת ב-[FRONTEND-API-GUIDE.md](../FRONTEND-API-GUIDE.md#7-טבלת-הרשאות-מלאה-36-endpoints). התיעוד המלא, עם דוגמאות, נמצא ב-Swagger: `/api-docs`.
